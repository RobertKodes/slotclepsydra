# slotclepsydra

Live Solana mainnet as a **clepsydra** (ancient water clock).

Water drips with the slot clock. Dye swirls ≈ recent txs by program family. Fill rate ≈ TPS. Surface foam/glow ≈ fee pressure. Failed txs leave red sediment. Cap the spout to freeze a sample.

Not an explorer. Not a dashboard. Not a newspaper.
